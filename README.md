# Movie Rating Prediction Model 🎬

This project uses machine learning to predict movie ratings based on historical data from the IMDb India dataset.

## 📊 Dataset
The dataset used in this project is `IMDb Movies India.csv`. It contains features like:
* **Name**: The title of the movie.
* **Year**: Release year.
* **Genre**: Category of the movie.
* **Director/Actors**: Key personnel involved.
